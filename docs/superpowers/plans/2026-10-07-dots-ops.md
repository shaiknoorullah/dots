# dots-ops Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automated system maintenance for every dots machine — updates, security, firmware, disk, performance modes, network, containers, Kubernetes clusters and backups — on schedules and triggers, safe actions automatic, risky actions waiting for a SwayNC Approve click, health visible in Waybar.

**Architecture:** No daemon. A small bash library (`lib.sh`) gives every job the same `log / state / notify / ask / lock / idle / run` API. User jobs run from chezmoi-managed files via a `dots-ops@.service` user template; root jobs run from root-owned copies in `/usr/local/lib/dots-ops` via a system template and report through `/var/lib/dots-ops/*.json`, which a user path unit relays into notifications. Approved root actions go through one allow-listed `sudo dots-ops-run <job> <action>`. Heavy jobs run only when idle (hypridle → `dots-ops-idle.target`) and on AC, with a 03:30 fallback.

**Tech Stack:** bash 5, jq, yq-go (TOML read), systemd (user + system units, path units, udev), SwayNC (`notify-send --wait --action`), hypridle, fzf, Waybar custom module, bats (tests), restic, smartmontools, lynis, fwupd, power-profiles-daemon, kubectl, docker CLI, chezmoi (files), Nix/home-manager (user tools).

**Spec:** `docs/superpowers/specs/2026-10-07-dots-ops-design.md` (approved 2026-10-07)

## Global Constraints

- Owner decisions O1–O6 (spec): tiered autonomy; desktop-only notifications (SwayNC + Waybar + `dots-ops status`); heavy jobs only when idle ≥ 15 min AND on AC, nightly fallback 03:30; scope includes backups, clusters, firmware, firewall + SSH; engine A (systemd + lib, no daemon); backup destination from `RESTIC_REPOSITORY`/`RESTIC_PASSWORD` in `~/.secrets`.
- **topgrade dropped (owner confirmed 2026-10-07; spec O5 amended):** topgrade is NOT used. It refuses to run as root and its user steps (npm/cargo/pipx/…) would upgrade tools that dots pins on purpose. System upgrades use each family's native command (apt/dnf/pacman); Nix/dotfile updates come from the repo via `chezmoi update`.
- Same behaviour on every distro: Arch, Debian/Ubuntu, Fedora/RHEL, NixOS (NixOS system parts via a Nix module).
- chezmoi owns user files; Nix owns user tools; root-run code lives only in root-owned paths (`/usr/local/lib/dots-ops`, `/usr/local/bin`) — never execute user-writable files as root.
- The only privilege path is `sudo /usr/local/bin/dots-ops-run <job> <action>`, allowed for group `dots-ops`, with `<job>`/`<action>` validated against existing root-owned action files.
- Every mutating command goes through `ops_run` so `DOTS_OPS_DRY_RUN=1` prints instead of executing.
- Notifications are state-change driven: ok→warn/fail once, re-notify failing at most every 24 h, one "recovered" on fail→ok.
- Approvals expire after 24 h (→ skip, re-asked next run); snooze = 24 h.
- Log: `~/.local/state/dots-ops/log.jsonl`, rotate at 10 MB, keep 30 days.
- No secrets in the repo; restic credentials only from the environment.
- Commit after each task; implementers commit only (controller pushes).

## Review Focus

1. **Root code reachable from a user-writable path** (privilege escalation) → Task 4 test asserts every system unit and the sudoers rule reference only root-owned paths, and `dots-ops-run` rejects `../`, unknown jobs and unknown actions.
2. **No notification daemon running** (TTY login, SwayNC crashed) → notifications must queue and appear next login, not be lost. Test: Task 1 bats with a failing fake `notify-send`.
3. **Laptop on battery or user active when a heavy job fires** → job exits 0 without doing work and logs why. Test: Task 2 bats `ops_idle_ok` with fake power-supply dirs.
4. **Distro without a feature** (Arch has no security channel, NixOS has no apt, no SMART-capable disks, no docker, no kubectl context) → job reports `ok` with an "n/a" summary or routes to Approve, never `fail`. Tests: per-domain bats with stubbed `os-release` and missing commands.
5. **Firewall/SSH first apply locking the owner out** → first apply is always an approval with a dry-run diff; sshd changes run `sshd -t` and only reload when authorized keys exist. Test: Task 9 bats.

```bash
#!/usr/bin/env bash
# dots-ops shared library — source it, never execute. Root and user both use this file.
: "${OPS_STATE:=${XDG_STATE_HOME:-$HOME/.local/state}/dots-ops}"
: "${OPS_ROOT_STATE:=/var/lib/dots-ops}"
: "${OPS_NOTIFY:=notify-send}"
: "${OPS_REMIND_SECS:=86400}"
: "${OPS_IS_ROOT:=$([ "$(id -u)" = 0 ] && echo 1 || echo 0)}"
mkdir -p "$OPS_STATE/state" "$OPS_STATE/pending" "$OPS_STATE/queue" "$OPS_STATE/locks" 2>/dev/null || true

ops_now() { date +%s; }

ops_log() {   # job level msg...
  local job=$1 level=$2; shift 2
  jq -cn --arg t "$(date -Is)" --arg j "$job" --arg l "$level" --arg m "$*" \
    '{t:$t,job:$j,level:$l,msg:$m}' >> "$OPS_STATE/log.jsonl"
  local size; size=$(stat -c%s "$OPS_STATE/log.jsonl" 2>/dev/null || echo 0)
  if [ "$size" -gt 10485760 ]; then
    mv "$OPS_STATE/log.jsonl" "$OPS_STATE/log.jsonl.$(date +%Y%m%d%H%M%S)"
    find "$OPS_STATE" -maxdepth 1 -name 'log.jsonl.*' -mtime +30 -delete
  fi
}

ops_run() {   # every mutating command goes through here
  if [ "${DOTS_OPS_DRY_RUN:-0}" = 1 ]; then printf '+ %s\n' "$*"; else "$@"; fi
}

ops_notify() {   # urgency title body — queue on failure (no daemon, TTY)
  local u=$1 t=$2 b=$3
  "$OPS_NOTIFY" -a dots-ops -u "$u" "$t" "$b" 2>/dev/null && return 0
  jq -cn --arg u "$u" --arg t "$t" --arg b "$b" '{u:$u,t:$t,b:$b}' \
    > "$OPS_STATE/queue/$(date +%s%N).json"
}

ops_flush_queue() {
  local f
  for f in "$OPS_STATE"/queue/*.json; do
    [ -e "$f" ] || continue
    "$OPS_NOTIFY" -a dots-ops -u "$(jq -r .u "$f")" "$(jq -r .t "$f")" "$(jq -r .b "$f")" 2>/dev/null \
      && rm -f "$f"
  done
}

ops_state() {   # job status summary — notifies on change (user context only)
  local job=$1 st=$2 sum=$3 dir prev notified now
  now=$(ops_now)
  if [ "$OPS_IS_ROOT" = 1 ]; then dir=$OPS_ROOT_STATE; mkdir -p "$dir"; else dir=$OPS_STATE/state; fi
  prev=$(jq -r '.status // "none"' "$dir/$job.json" 2>/dev/null || echo none)
  notified=$(jq -r '.notified // 0' "$dir/$job.json" 2>/dev/null || echo 0)
  local send=""
  if [ "$OPS_IS_ROOT" != 1 ]; then
    if [ "$st" != ok ] && { [ "$prev" != "$st" ] || [ $((now - notified)) -ge "$OPS_REMIND_SECS" ]; }; then send=$st
    elif [ "$st" = ok ] && [ "$prev" != ok ] && [ "$prev" != none ]; then send=recovered; fi
  fi
  case $send in
    fail)      ops_notify critical "dots-ops: $job failed" "$sum"; notified=$now ;;
    warn)      ops_notify normal   "dots-ops: $job" "$sum"; notified=$now ;;
    recovered) ops_notify low      "dots-ops: $job recovered" "$sum"; notified=0 ;;
  esac
  jq -cn --arg j "$job" --arg s "$st" --arg m "$sum" --argjson t "$now" --argjson n "$notified" \
    '{job:$j,status:$s,summary:$m,changed:$t,notified:$n}' > "$dir/$job.json.tmp" && mv "$dir/$job.json.tmp" "$dir/$job.json"
  ops_log "$job" "$st" "$sum"
}

ops_lock() {   # job — exits 0 if another instance holds the lock
  exec {OPS_LOCK_FD}>"$OPS_STATE/locks/$1.lock"
  flock -n "$OPS_LOCK_FD" || { ops_log "$1" info "already running; skipped"; exit 0; }
}
```

```bash
: "${OPS_ASK_UI:=1}"
: "${OPS_SUDO:=sudo}"
: "${OPS_IDLE_FLAG:=${XDG_RUNTIME_DIR:-/run/user/$(id -u)}/dots-ops/idle}"
: "${OPS_POWER_DIR:=/sys/class/power_supply}"

ops_ask() {   # job question action — one live pending per job
  local job=$1 q=$2 act=$3 now; now=$(ops_now)
  ops_ask_pending "$job" && return 0
  jq -cn --arg q "$q" --arg a "$act" --argjson t "$now" --argjson e $((now + 86400)) \
    '{question:$q,action:$a,asked:$t,expires:$e,snooze_until:0}' > "$OPS_STATE/pending/$job.json"
  ops_log "$job" ask "$q"
  [ "$OPS_ASK_UI" = 1 ] && command -v setsid >/dev/null && setsid -f dots-ops-ask "$job" >/dev/null 2>&1
  return 0
}

ops_ask_pending() {   # 0 = live pending (or snoozed) exists
  local f="$OPS_STATE/pending/$1.json" now; now=$(ops_now)
  [ -f "$f" ] || return 1
  if [ "$(jq -r .expires "$f")" -le "$now" ] && [ "$(jq -r .snooze_until "$f")" -le "$now" ]; then
    rm -f "$f"; ops_log "$1" info "approval expired; skipped"; return 1
  fi
  return 0
}

ops_answer() {   # job approve|skip|snooze
  local job=$1 ans=$2 f="$OPS_STATE/pending/$1.json" act
  [ -f "$f" ] || return 0
  act=$(jq -r .action "$f")
  case $ans in
    approve)
      rm -f "$f"; ops_log "$job" approve "$act"
      case $act in
        user:*) bash -c "${act#user:}" ;;
        root:*) set -- ${act#root:}; "$OPS_SUDO" /usr/local/bin/dots-ops-run "$1" "$2" ;;
      esac ;;
    skip)   rm -f "$f"; ops_log "$job" skip "$act" ;;
    snooze) jq --argjson s $(( $(ops_now) + 86400 )) '.snooze_until=$s' "$f" > "$f.tmp" && mv "$f.tmp" "$f"
            ops_log "$job" snooze "$act" ;;
  esac
}

ops_on_ac() {
  local d bat=0
  for d in "$OPS_POWER_DIR"/*; do
    [ -e "$d/type" ] || continue
    case $(cat "$d/type") in
      Mains) [ "$(cat "$d/online" 2>/dev/null)" = 1 ] && return 0 ;;
      Battery) bat=1 ;;
    esac
  done
  [ "$bat" = 0 ]   # no battery = desktop = AC
}

ops_idle_ok() {
  ops_on_ac || return 1
  [ -e "$OPS_IDLE_FLAG" ] && return 0
  [ "${OPS_FALLBACK:-0}" = 1 ] && pgrep -x hyprlock >/dev/null 2>&1 && return 0
  [ "${OPS_FALLBACK:-0}" = 1 ] && ! loginctl list-sessions --no-legend 2>/dev/null | grep -q . && return 0
  return 1
}
```

```bash
# pins-check: weekly; compares extra-tools.yaml pins and the nixpkgs lock age with upstream.
: "${OPS_DOTS_REPO:=$(git -C "$(chezmoi source-path)" rev-parse --show-toplevel 2>/dev/null)}"
pins_latest() {   # kind name -> latest version on stdout, non-zero on failure
  local enc
  case $1 in
    npm)   enc=$2; curl -fsS --max-time 15 "https://registry.npmjs.org/$enc/latest" | jq -er .version ;;
    cargo) curl -fsS --max-time 15 -A "dots-ops pins-check" "https://crates.io/api/v1/crates/$2" | jq -er .crate.max_stable_version ;;
    pipx|uv) curl -fsS --max-time 15 "https://pypi.org/pypi/$2/json" | jq -er .info.version ;;
  esac
}
job_main() {
  local y="$OPS_DOTS_REPO/home/.chezmoidata/extra-tools.yaml" out="[]" failed=0 kind name from to auto
  [ -f "$y" ] || { ops_state pins-check ok "n/a: no dots repo"; return 0; }
  while IFS=$'\t' read -r kind name from; do
    to=$(pins_latest "$kind" "$name") || { failed=1; continue; }
    [ "$to" = "$from" ] && continue
    auto=true; [ "$kind" = uv ] && auto=false
    out=$(jq -c --arg k "$kind" --arg n "$name" --arg f "$from" --arg t "$to" --argjson a "$auto" \
      '. + [{kind:$k,name:$n,from:$f,to:$t,auto:$a}]' <<<"$out")
  done < <(yq -r '(.extraTools.npm[] | "npm\t\(.name)\t\(.version)"),
                  (.extraTools.cargo[] | "cargo\t\(.crate)\t\(.version)"),
                  (.extraTools.pipx[] | "pipx\t\(.name)\t\(.version)"),
                  (.extraTools.uv[] | "uv\t\(.name)\t\(.version)")' "$y")
  printf '%s\n' "$out" > "$OPS_STATE/pins-candidates.json"
  local n age days max sum=""
  n=$(jq length <<<"$out")
  age=$(jq -r '.nodes.nixpkgs.locked.lastModified // 0' "$OPS_DOTS_REPO/nix/flake.lock")
  days=$(( ( $(date +%s) - age ) / 86400 )); max=$(ops_cfg pins.lock_max_days 30)
  [ "$n" -gt 0 ] && sum="$n pins behind: $(jq -r 'map("\(.name) \(.from)→\(.to)\(if .auto then "" else " (manual)" end)")|join(", ")' <<<"$out")"
  [ "$days" -gt "$max" ] && sum="${sum:+$sum; }nixpkgs lock $days days old"
  [ "$failed" = 1 ] && sum="${sum:+$sum; }check failed for some registries"
  if [ -z "$sum" ]; then ops_state pins-check ok "all pins current"; return 0; fi
  ops_state pins-check warn "$sum"
  if [ "$(jq '[.[]|select(.auto)]|length' <<<"$out")" -gt 0 ] || [ "$days" -gt "$max" ]; then
    ops_ask pins-check "$sum — open a bump PR?" "user:dots-ops pins-bump"
  fi
}
```
